[10-13 seg]
"Solo novecientos noventa y nueve pesos"

[13-15 seg]

| Tiempo | Visual | Texto en Pantalla |
|--------|--------|-------------------|
| 0-3s | Imagen de código/laptop | "¿Quieres ganar más como programador?" |
| 3-6s | Logos de tecnologías animados | "Full Stack en 8 semanas" |

## 🎬 ANUNCIO 5: Problema-Solución Directo (18 segundos)

### Concepto
Formato clásico de marketing: presentar el problema, agitarlo, dar la solución. Hook fuerte en los primeros 3 segundos.

### Guión para ElevenLabs

```
[Voz: Masculina, tono directo y confiado]

[0-3 seg - HOOK]
"La universidad NO te enseña a programar de verdad"

[3-7 seg - PROBLEMA]
"Te dan pura teoría... pero nunca construyes nada real"

[7-12 seg - SOLUCIÓN]
"Por eso creé un curso donde construyes una app completa en ocho semanas"

[12-15 seg - OFERTA]
"PHP, SQL Server, JavaScript... todo por solo novecientos noventa y nueve pesos"

[15-18 seg - CTA]
"Quedan nueve lugares. Haz clic ahora."
```

### Secuencia Visual

| Tiempo | Visual | Efecto |
|--------|--------|--------|
| 0-3s | Texto grande: "La universidad NO te enseña..." | Zoom in rápido |
| 3-7s | Imagen de libros/aula vs código real | Split screen |
| 7-12s | Tu foto + screenshots del curso | Transición suave |
| 12-15s | Precio animado con descuento | Bounce effect |
| 15-18s | CTA + countdown visual | Urgencia |

## 🎯 Segmentación Recomendada

### Ubicación
- **Solo México** ✅
- Ciudades principales: CDMX, Guadalajara, Monterrey, Puebla, Querétaro

### Edad
- 20-35 años

### Intereses
- Programación
- Desarrollo web
- JavaScript
- PHP
- Bases de datos
- Tecnología
- Emprendimiento digital
- Diseño web
- Computación

### Comportamientos
- Usuarios de dispositivos Android y iOS
- Compradores en línea

### Exclusiones
- Personas que ya visitaron página de éxito de pago
- Personas que ya interactuaron con anuncios anteriores (para testing limpio)

## 📊 Métricas a Monitorear

| Métrica | Objetivo | Acción si no se cumple |
|---------|----------|------------------------|
| CTR | > 1.5% | Cambiar creative/copy |
| CPC | < $0.50 USD | Ajustar segmentación |
| Retención video 3s | > 60% | Mejorar hook inicial |
| Retención video 50% | > 25% | Acortar video |
| Conversiones | > 0.5% | Revisar landing page |
