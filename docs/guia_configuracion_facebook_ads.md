2. Selecciona **"Crear campaña nueva"**

| Campo | Valor |
|-------|-------|
| **Nombre de campaña** | `FullStack-Ventas-Enero2026-v2` |

| **Tipo de compra** | Subasta (predeterminado) |

## 🔄 PASO 6: Crear Variaciones (A/B Testing)

Para los 5 anuncios diferentes:

### Opción A: Duplicar dentro del mismo conjunto
1. Ve al conjunto de anuncios creado
2. Clic en **"Duplicar"** en el anuncio
3. Cambia el nombre y el creative
4. Repite para cada variación

### Opción B: Crear conjuntos separados (recomendado para testing)
1. Duplica el conjunto de anuncios completo
2. Cambia el nombre: `MX-20-35-Video1-ProblemaSolucion`
3. Dentro, cambia el creative

### Estructura sugerida:


## ⚠️ Problemas Comunes y Soluciones

### "Anuncio rechazado"
- Revisa que no haya promesas exageradas de dinero
- Verifica que la imagen no tenga más del 20% de texto
- Asegura que la landing page funcione

### "Aprendizaje limitado"
- Aumenta el presupuesto
- Combina conjuntos de anuncios
- Cambia a evento de conversión más arriba del funnel (ViewContent en vez de Purchase)

### "CPM muy alto"
- Audiencia muy pequeña → Amplía intereses
- Competencia alta → Cambia creativos
- Baja relevancia → Mejora el copy

### "Sin conversiones después de 3 días"
- Revisa que el Pixel esté funcionando
- Verifica que la landing page cargue rápido
- Prueba con objetivo de "Tráfico" para obtener datos
