## 💡 Notas para el Instructor

### **Cómo Usar Estos Archivos:**

1. **Antes de la clase:**
   - Abre todos los archivos en pestañas separadas
   - Ejecuta `01_setup_inicial.sql` en tu phpMyAdmin
   - Ten listos para compartir pantalla

2. **Durante la clase:**
   - Comparte pantalla con el archivo correspondiente
   - Lee los comentarios en voz alta
   - Ejecuta el código línea por línea
   - Pausa para que los alumnos copien y ejecuten

3. **Timing:**
   - Usa un timer visible
   - Si un ejercicio toma más tiempo, acorta el siguiente
   - Prioriza la práctica sobre la teoría

4. **Compartir con alumnos:**
   - Al final de la clase, sube todos los archivos al grupo
   - Los alumnos pueden usarlos para repasar
   - El archivo 08 es para tarea
