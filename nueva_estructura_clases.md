### **Módulo 2: Bases de Datos y Conexión** (Clases 5-8)

#### 🆕 **Clase 5: SQL Avanzado**
**Temas:**
- Tipos de Joins:
  - `INNER JOIN`
  - `LEFT JOIN`
  - `RIGHT JOIN`
- Subconsultas (subqueries)
- Funciones agregadas:
  - `COUNT()`, `SUM()`, `AVG()`, `MIN()`, `MAX()`
- Agrupación de datos:
  - `GROUP BY`
  - `HAVING`
- Alias y renombrado de columnas

---

#### 🆕 **Clase 6: Conexión PHP + Base de Datos (PDO)**
**Temas:**

- Ejecutar queries SELECT desde PHP
- Manejo de errores con try-catch

- Fetch de datos (fetch, fetchAll)
- Parámetros nombrados vs posicionales

- Validación de datos
- Mensajes de éxito/error
- Proyecto práctico: Sistema de gestión de productos

#### 🆕 **Clase 8: SQL Server Avanzado**
**Temas:**

- Índices y optimización de queries
- Conexión desde PHP usando sqlsrv

## 🎯 Progresión Pedagógica

### **Orden Lógico de Aprendizaje:**
1. ✅ **Backend primero** → Entiendes cómo funciona el servidor
2. ✅ **SQL antes de PDO** → Sabes qué queries ejecutar antes de conectar
3. ✅ **CRUD completo** → Integras PHP + SQL en proyectos reales
4. ✅ **Frontend después** → Mejoras la interfaz de lo que ya funciona
5. ✅ **Proyecto final** → Integras todo lo aprendido
